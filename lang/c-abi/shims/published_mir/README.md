# Published lifecycle object results

Status: active owner; Borrowed/Mixed/field connection remains unaccepted WIP.
Scope: structural result transport, Return correspondence and object outcome.
Related: [shims](../README.md), `hako_llvmc_ffi_lifecycle_v4_indexed_object_result.inc`,
`hako_llvmc_ffi_lifecycle_v4_object_result_emit.inc`.

Ordinary Handle/NullableHandle Returns require the source-issued `result_origin`
column. The existing object-result index checks exact producer/Invoke/Normal
coordinates and every ordered original Copy through the final Return value;
missing columns never retry shape-based inference. Nonnullable admits Fresh or
OwnedCall; nullable additionally admits the original Null constant. Existing
class, LIVE lease transfer and Fault laws remain mandatory. Mixed and borrowed
results use distinct kinds and obligations below; neither is an ordinary Home.

Internal Handle/Nullable calls also carry an outcome out-slot beside payload.
Only their Normal producer reads it and checks exact Null0/Fresh1 correspondence;
Fault leaves it unread. Return selects the original result_origin's outcome.
The same indexed original Copy-root projection lends the companion to Birth,
Provided storage and nullable cleanup. Ordinary borrowed formals, receivers,
field borrows and Array values gain no outcome or Home. External/root/runtime
ABIs and scalar, Unit and Map result transports retain their existing forms.

Schema and indexed flow share one structural result-to-callee-role mapping.
Emission uses the same object-result predicates; source proof and lease checks
remain with their existing owners. Unknown result words always refuse.

Borrowed nullable results use a dedicated non-owning kind. Their fixed logical
formal is not a receiver or LLVM-lane index. The same original Call maps the
callee ordinal through its actual to the caller's original anchor; bounded
Copy-root traversal cannot invent or replace that anchor. Normal and Copy reads
require its existing lifetime. The Normal block must have exactly one incoming
edge, the SAME Invoke Normal edge, before any result slot is read.

The retained current source law admits original Null or the same fixed formal,
with every ordered original Copy through Return. The borrowed Return checker
walks all Returns; it does not consume an owned slot. Other Homes must already
be discharged. Borrowed results produce no LIVE obligation and cannot enter
owned move/release paths. Their Normal companion is exactly0 for payload0 or2
for nonzero Forward; fixed formals validate the object/null tag domain before
callee effects, including when no concrete object_view is imposed.

Borrowed function/Call schemas and Rust JSON carry the same mandatory logical
ordinal; the declared formal must exist with its borrowed representation and
Call metadata must agree with the callee. Native admission rejects this object
cohort. Source-issued positive and independent negative C execution remain
mandatory before accepting this connection. Successful owned regressions are not
Borrowed/Mixed execution evidence.

Mixed Returns corroborate all original Null/Fresh/OwnedCall/BorrowedCall rows.
BorrowedCall substitutes the callee's fixed INNER ordinal through the SAME Call
actual and Copy root, then requires this function's fixed OUTER formal. They
are separate ordinal domains. Acquired alternatives alone supply owned class;
Forward does not acquire that class. Current Mixed source seals issue no outgoing
anchored-field End plan, so Mixed Return field-support groups stay refused.

Mixed uses a dedicated conditional state260, separate from LIVE, Map transfer,
Birth field markers and Array obligations. Its Normal projection, Copy and null
comparison require the original support's lifetime. Birth consumes260 on Normal
only; Fault retains it for original cleanup. General Home/reclaim consumers
refuse this kind. The Normal pair is exactly payload0/outcome0, or nonzero
payload/outcome1(Fresh) or2(Forward); Fault reads neither output slot.

Each outgoing owned field group transports six original projections: canonical
field/child/constructor ordinal, OUTER formal ordinal, entry Value, ordered
Copies, INNER Call Invoke/Normal/ordinal, and optional exact Birth coordinate.
A constructor ordinal is distinct from INNER and OUTER. C checks the canonical
Provided store, actual substitution and every callee Return dependency on relay.
Every Fresh Return of a Mixed Birth wrapper must retain its own dependencies.
Read/End checks rebase them onto this invocation's actuals, including parent
wrapper dependencies for field reads; finite traversal refuses cycles.

Provided residence carries the original outcome beside kind/payload. Constructor
guards admit null0 or object1/2. Atomic residence storage/read retains it; no
legacy-slot retry is allowed. ObjectEndIfOwned carries the retained full End
body, corroborated against all marked layout contents in reverse order and the
outer release. Only outcome1 runs the existing complete End helper;0/2 skip
both children and outer storage. home_release_if_live keeps its separate
outer-only responsibility. Local Mixed field storage without the returned
construction/source support remains refused.

Field-resident Array Get/Set/Push share one indexed residence validator in
`hako_llvmc_ffi_lifecycle_v4_field_array_flow.inc`. Copy roots must reach the
original field read, whose canonical tuple is a unique owned Array residence
with one Birth store from the exact Array allocation. Parent readability and
field stability are checked at the read and use, including residence release.
Push accepts source-issued I64 or an explicit Text descriptor. Text uses the
shared String operand schema/liveness/global-byte/descriptor writers and
`nyash.array.checked_append_text_v1`; both parent residence and Text lease are
checked in the Array branch, never bypassed through generic String flow. Static
UTF-8 keeps its exact bytes, including NUL; owned/borrowed input stays borrowed
on both outcomes while runtime copies it independently. Native numeric Array
and NormalInteger-as-Text remain refused. One Array emitter projects primitive
copies and owned-slot operations; the same parent/child cleanup owners remain.
Neither outcome consumes the parent lease. A raw I64 payload is never Array provenance. Birth
internal Array reads remain refused here until their commit-marker consumer
is connected. Native Script Array keeps its separate existing claim consumer.

Field Map has/get share the Text operand table and descriptor writer. Indexed
get retains separate field-object and payload-object identities and calls the
existing `nyash.object.checked_map_field_get_v1`; no Map pointer escapes.
Array and Map get use one non-owning slot projection in the existing value
index. Map Copy/checked scalar reads recheck the original unique Normal, parent
liveness and unchanged field/slot interval. Replacement, drain, Map mutation
and unproved Calls in that interval refuse. No key lease is re-decoded after
get. Raw nullable field access, Map-slot Call/Return and owning End remain
unadmitted until their original source support consumers close.

Borrowed Text uses the existing kind/payload pair with the closed physical
formal declaration `text_view: true`, `object_view: null`, and
`representation: "borrowed_kind_payload_v1"`. Input views are independent of
the ordinary result lane. A borrowed object result's supporting formal cannot
claim a scalar-only view. Unmarked formals retain their original tags0..3 domain.
Every incoming edge must supply either a named `borrowed_text` actual containing
a `static_text` or live `owned_string` operand, or a `tagged` forward of the SAME
Text formal through original Copies. Numeric tag4 constructors, scalar actuals,
cross-domain forwards and inferred Text domains refuse before emission.

The caller creates the synchronous descriptor per Call argument ordinal. Runtime
tag4 points to that caller-owned `NyrtStringOperandV1`, restricted to static or
owned String kind1/2. Forwarding preserves the same tag/pointer. A String
`borrowed_text` operand must resolve to its exact marked formal/Copy root;
emission checks tag, nonzero aligned pointer and descriptor kind before use.
The borrow neither acquires nor consumes the caller's String pair on Normal or
Fault. Callee String Add may acquire its own separately discharged pair. Borrowed
Text cannot be Ended, stored, returned, used as a scalar or object anchor, or
silently admitted into a generic tagged domain. Empty and embedded-NUL text use
the same descriptor contract. This backend capability issues no source proof:
Rust must retain and verify the original closed Text entry authority before
publishing the marker; physical fixture success cannot remove source fences.

A finite source input instead carries `finite_domain`, a nonempty canonical
subset of `["null", "i64", "bool", "text"]`, with null `object_view` and no
exclusive view marker. It names the original source SUM, not a guessed runtime
type. Schema rejects duplicates, unknown classes, noncanonical order and mixed
markers. Concrete actuals require membership; tagged forwards require a known
caller domain contained in the callee domain. Entry checks tag and Null/Bool
payload without projecting the mixed input into one scalar class.

Text membership does not grant a Text-only read. Source-authorized String Add
uses its explicit tagged operand: tag4 takes the SAME live descriptor checks
above and copies the descriptor, while other tags retain the existing String
Dynamic operand ABI and TypeError behavior. It creates no input owner or End.
The separate Dynamic invocation ABI still refuses finite inputs containing Text;
its tagged transport accepts tags0..3 and has no Text descriptor consumer.

This is the implemented consumer contract, not an execution acceptance claim.
The unchanged app's canonical direct EXE/run/output/exit and independent source,
wire-correspondence and Fault evidence must establish the complete connection.
