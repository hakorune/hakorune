## One Decision

Decision: connect original Text-producing expressions to ordinary static borrowed
input in the existing source/packet/physical pipeline. Build the missing source
and consumer connections; lack of already finished packets is not a construction
stop. Read-only source and physical workers reviewed the complete responsibility.

Source authority + canonical issuer:
- Original resolver method rows and ExpressionSourcePlanV1; the original static
  incoming Rc, formal ordinal, receiver and complete ordered actuals.
- Original seed product/incoming/Return source provides a sum of Text, signed
  Integer, Null and retained unresolved/other dependencies. No false homogeneous
  Text agreement and no dropping uncalled wrappers/incoming edges.
- For concatenation, choose the two EXISTING Add(String,String) and
  Add(String,NormalInteger) envelopes on their proved source alternatives. The
  original terminating null arm accounts for Null. Unknown is not Text|Integer.
  No general String×Dynamic execution semantics are selected. The result
  catalog's ExactStringOnSuccess is representation only, not execution permission.
- Generated StringSubstring/2 CoreMethod row supplies Text receiver, I64 bounds,
  TextToCaller. Ordinary argument selection must retain its own original source
  and proofs; bounded Loop membership cannot be borrowed or fabricated.

Physical borrowing contract selected for construction:
- Existing ordinary kind/payload ABI tags0..3 retain their meaning. Add an explicit
  Text borrow runtime tag4 with payload pointing to a caller-owned synchronous
  NyrtStringOperandV1 descriptor: kind1 static text or kind2 exact owned pair.
  This is neither object tag3 nor ExactText(slot,generation); End-token and
  generation must never be aliased. Descriptor kind3 integer is NOT Text.
- JSON keeps numeric tags0..3 unchanged. A named borrowed_text form carries the
  original operand/proof, never a numeric pointer. Caller emission creates a
  descriptor per callsite/ordinal in its entry frame, fills it before the call,
  and forwards the same pointer through nested borrowed calls. Callee cannot
  store, return, share or End it; caller-frame-destroying tail calls are excluded.
- Caller retains the original pair and its End obligation until the complete
  call outcome. Normal and Fault End acquired argument temporaries in reverse
  source acquisition order. A failed substring creates no result to End.
- Reuse hako.text.scan.substring.v1 CodePoint/clamped semantics and its checked
  Normal/Fault result; adapt to the existing FaultFrame/root graph, not a new
  substring evaluator or unchecked legacy helper. Both transport return and
  DynamicV2CallOut status must be checked with their existing owner contract.

Non-authority: selectors/names, MIR types, success representation alone, runtime
class guesses, fabricated loop keys, literal-only replacement of the actual
source, erased incoming rows, generic object handles or copied ownership tokens.
Fail-fast boundary: missing source/domain/bounds/entry/descriptor/producer/End or
original identity refuses before effects/artifact. Text cannot relax object0/3,
Fault-frame, incompatible String-operand or unused-argument checks.
