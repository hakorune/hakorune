# A-prime exact-I64 physical capability

This module owns the bounded, Builder-free demand for the selected
`ParserScanLoopBox.skip_while/4` Dynamic cohort after its source parameters
are sealed as exact `i64` contracts.

The issuer consumes only the installed package loan and borrows two sibling
views from the package-held `VerifiedDynamicExitTransactionCoSealV1`:

- the exact source/Recipe relation for `pos`, `end`, the induction binding,
  the two Completion sites, and the selected Loop source;
- the complete Dynamic physical-input relation, including placement,
  operation source/effect, exact `CallSlot` evidence, logical transfer, and
  Fault coverage.

The resulting demand contains no `ValueId`, `BasicBlockId`, MIR instruction,
backend tag, ABI helper, or fallback. A later fresh physical session must
materialize those facts and publish its own session-local receipt. This module
does not re-observe AST/source, reissue Dynamic semantics, or select a backend.

`VerifiedResolvedCallableSourceIdentityV1` is a private comparison/navigation
view borrowed from the same resolved batch row. It is not a callable key,
batch slot, or lowering authority.
